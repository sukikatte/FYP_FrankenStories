# Story Seeds Collection

## Generation Process

The initial seed directions were drafted with help from GPT-4.1, using the `poses` and `settings` fields from `element_library.json` as the source scope.  
Based on those drafts, I then manually selected, refined, and edited the final set of themes, which became the current `story_seeds.json`.

## Design Principles

- Themes relate to the element library to prevent Hallucination
- Do not specify element names; model selects characters, poses, and settings
- Provide basic scene + simple event; control length to 1-2 sentences

## Usage

- Use each theme in Method A and Method B
- Generate 3-5 ComicXML outputs per theme for stability and breadth analysis
